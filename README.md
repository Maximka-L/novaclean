# 🚀 NovaClean — Android Cleaner, Optimizer & Security Toolkit

Современное, безопасное и производительное Android-приложение для глубокой очистки памяти, сжатия медиафайлов, поиска тяжелого контента и обеспечения цифровой конфиденциальности. 

Разработано на **Kotlin 2.0+** с использованием декларативного интерфейса **Jetpack Compose (Material Design 3)** в строгом соответствии с принципами **Clean Architecture**.

👉 **Репозиторий проекта**: [https://github.com/Maximka-L/novaclean](https://github.com/Maximka-L/novaclean)

---

## 🌟 Возможности приложения

### 1. 🧹 Комплексная очистка хранилища
- 📸 **Дубликаты фото**:
  - Быстрое хеширование (MD5 первых 64 КБ + размер).
  - Выделение точных копий с автоотметкой лучшего кадра.
  - Кластеризация похожих кадров и серийных снимков (Burst).
- 🎵 **Дубликаты музыки и аудио**:
  - Поиск одинаковых треков по метаданным, длительности и содержимому.
- 👥 **Очистка и объединение контактов**:
  - Нормализация номеров (`+7`, `8`, скобки, дефисы).
  - Безопасное объединение дубликатов телефонной книги в один клик.
- 🗑️ **Очистка системного мусора**:
  - Удаление 0-байтовых поврежденных файлов.
  - Очистка пустых остаточных папок удаленных приложений.
  - Поиск забытых установочных пакетов `.apk` и временных файлов (`.tmp`, `.log`).

### 2. 🗜️ Сжатие медиа (Media Compressor)
- Уменьшение размера фотографий на 60–80% без видимой потери качества.
- 3 пресета: *Максимальное сжатие (50%)*, *Сбалансированное (70%)*, *Легкое сжатие (85%)*.
- Встроенная защита от Out-Of-Memory при обработке фото сверхвысокого разрешения (до 108 Мп).
- Наглядный предварительный расчет экономии дискового пространства до применения.
- Freemium-модель (2 бесплатных сжатия, безлимитный пакетный режим в PRO).

### 3. 🐘 Поиск больших файлов (Large Files Finder)
- Мгновенное сканирование накопителя через Scoped `MediaStore API`.
- Фильтры по объему: `> 50 МБ`, `> 100 МБ`, `> 500 МБ`, `> 1 ГБ`.
- Категоризация: *Все*, *Видео*, *Аудио*, *Документы*, *Архивы*.
- Пакетное выделение и удаление тяжелых файлов с контролем освобождаемого места.

### 4. 🗄️ Секретный Сейф (Private Vault)
- Защищенное изолированное хранилище во внутренней директории приложения (`context.filesDir/vault`), скрытое от стандартной системной галереи.
- Защита 4-значным PIN-кодом с криптографическим хешированием SHA-256 с солью.
- Разделы: *Секретные фото* и *Личные заметки*.
- Функции быстрого импорта, просмотра, удаления и восстановления обратно в общее хранилище.
- Эксклюзивная функция NovaClean PRO.

### 5. 📱 Виджет на рабочий стол (Home Screen Widget)
- Виджет рабочего стола в стиле Material 3 (`NovaCleanWidgetProvider`).
- Индикация % занятости ОЗУ и хранилища устройства в реальном времени.
- Кнопка **«Очистить»**: мгновенная оптимизация кэша в один тап прямо с домашнего экрана (через `ACTION_QUICK_CLEAN`).

### 6. ⏰ Умные фоновые уведомления (WorkManager)
- Фоновый мониторинг свободного места (`StorageMonitorWorker`) с запуском раз в 3 дня.
- Автоматическое уведомление пользователя при критическом заполнении памяти (< 15% свободного места).
- Поддержка разрешений Android 13+ (`POST_NOTIFICATIONS`) и возможность отключения в настройках.

### 7. ⚡ Оптимизация памяти (ОЗУ)
- Мониторинг занятой и доступной оперативной памяти в реальном времени через `ActivityManager.MemoryInfo`.
- Безопасная очистка внутренних буферов приложения, кэшей эскизов и вызов GC JVM.
- Полное соответствие требованиям Google Play (без рискованного `KILL_BACKGROUND_PROCESSES`).

### 8. 🔐 Генератор и Менеджер паролей (в стиле Kaspersky / Vault)
- **Генератор паролей**:
  - Криптографически надежная генерация на базе `SecureRandom`.
  - Градиентная шкала надежности пароля и расчет энтропии (в битах).
  - Оценка времени, необходимого для взлома методом перебора (брутфорс).
  - Исключение неоднозначных символов (`0/O`, `1/l/I`) и быстрое копирование.
  - Сохранение сгенерированного пароля в Менеджер в один клик.
- **Оффлайн Менеджер паролей**:
  - Надежное симметричное шифрование **AES-256 (CBC/PKCS5Padding)** с уникальным случайным вектором инициализации (IV) для каждой записи.
  - Категории аккаунтов: *Все*, *Соцсети*, *Почта*, *Финансы*, *Работа*, *Другое*.
  - Полнотекстовый поиск по названию сервиса, логину и заметкам.
  - Маскирование паролей с возможностью скрытия/отображения.
  - Быстрое копирование логина и пароля в буфер обмена в один тап.
  - 100% приватность: база хранится исключительно во внутреннем изолированном хранилище приложения, без отправки в интернет.

### 9. 👤 Личный кабинет, регистрация и статистика
- Локальная регистрация и персонализация профиля (Имя, E-mail).
- Индикатор статуса учетной записи и PRO-подписки.
- Прямой доступ к Менеджеру паролей из настроек профиля.
- Наглядный счетчик сэкономленного пространства за все время использования.
- Управление умными уведомлениями и ссылки на политики безопасности.

### 10. 💳 Монетизация подписками (Google Play Billing 7.x)
- Тарифные планы: *1 Год* (с 3 днями триала), *1 Месяц*, *Навсегда (Lifetime)*.
- Поддержка официального Google Play Billing Client 7.1.1.
- Встроенный отладочный Sandbox Fallback для тестирования покупки и восстановления без боевой консоли.

### 11. 📢 Рекламная сеть Яндекса (РСЯ / Yandex Mobile Ads SDK)

## 🛡️ Политики безопасности и соответствие Google Play Store

Приложение полностью адаптировано под актуальные требования Google Play Console:
1. **Никаких "Task Killers"**: Удалено разрешение `android.permission.KILL_BACKGROUND_PROCESSES` и методы принудительного завершения фоновых процессов других приложений.
2. **Scoped Storage**: Приложение работает через официальные контракты `MediaStore` и `PickVisualMedia` без запроса опасного разрешения `MANAGE_EXTERNAL_STORAGE`.
3. **Честный UI**: Все формулировки приведены к стандартам прозрачности (оптимизация кэша и памяти без ложных заявлений о замедлении/ускорении стороннего ПО).
4. **Конфиденциальность**: 100% данных обрабатываются локально на устройстве пользователя.

## 🏗️ Архитектура

Проект построен по модульным принципам **Clean Architecture**:

```
app/src/main/java/com/novaclean/app/
├── domain/            # Бизнес-логика (чистый Kotlin без привязки к Android SDK)
│   ├── model/         # Модели предметной области (LargeFileItem, VaultItem, CompressionConfig и др.)
│   ├── repository/    # Интерфейсы репозиториев
│   └── usecase/       # Интеракторы (CompressMediaUseCase, ScanLargeFilesUseCase, VaultUseCases и др.)
├── data/              # Работа с источниками данных
│   ├── datasource/    # MediaStoreDataSource, MemoryDataSource, ContactsDataSource, FileSystemDataSource
│   └── repository/    # Реализации репозиториев (Compressor, LargeFiles, Vault, Profile, Billing)
├── presentation/      # Пользовательский интерфейс (Jetpack Compose + Material 3)
│   ├── components/    # Переиспользуемые виджеты (CircularGauge, ActionButtons, CategoryCard, ProBadge)
│   ├── navigation/    # Навигационный граф Jetpack Navigation Compose
│   ├── screens/       # Экраны (Dashboard, Compressor, LargeFiles, Vault, Photos, Junk, Paywall и др.)
│   ├── theme/         # Цветовая палитра (NeonCyan, ElectricBlue, MintGreen, DarkSurface) и типографика
│   └── viewmodel/     # Реактивные ViewModel с поддержкой StateFlow
├── widget/            # Виджет рабочего стола NovaCleanWidgetProvider
├── worker/            # Фоновые воркеры WorkManager (StorageMonitorWorker)
└── di/                # Внедрение зависимостей (AppContainer)
```

## 🚀 Сборка и запуск проекта

### Требования
- JDK 17 (рекомендуется OpenJDK 17)
- Android SDK (API 35, Build-Tools 35.0.0)

### Команды для терминала

```bash
# Клонировать репозиторий
git clone git@github.com:Maximka-L/novaclean.git
cd novaclean

# Установить JAVA_HOME (для macOS с Homebrew)
export JAVA_HOME="/opt/homebrew/opt/openjdk@17"

# Запуск Unit-тестов
./gradlew test

# Сборка Debug APK
./gradlew assembleDebug

# Сборка подписанного Release APK для RuStore
./gradlew assembleRelease
```

Собранные файлы:
- **Debug APK**: `app/build/outputs/apk/debug/app-debug.apk`
- **Release APK для RuStore**: `app/build/outputs/apk/release/app-release.apk` (подписан цифровым ключом `app/novaclean-release.jks`, готов к загрузке в консоль RuStore)

## 📄 Локализация

Все пользовательские строки и сообщения полностью вынесены в `app/src/main/res/values/strings.xml` — в коде Jetpack Compose отсутствуют жестко закодированные текстовые литералы, что обеспечивает легкую мультиязычную адаптацию.
