# 🚀 NovaClean — Android Cleaner & Security Toolkit

Современное Android-приложение для оптимизации памяти, поиска дубликатов и обеспечения цифровой безопасности. Написано на **Kotlin** с использованием **Jetpack Compose (Material 3)** и архитектуры **Clean Architecture**.

---

## 🌟 Основные возможности

1. 📸 **Поиск дубликатов фото**:
   - Мгновенное хеширование (MD5 первых 64 КБ + размер).
   - Точные дубликаты с автовыбором лучшего кадра.
   - Кластеризация похожих снимков (серийная съемка Burst).
2. 🎵 **Поиск дубликатов музыки**:
   - Анализ аудиофайлов по метаданным, длительности и содержимому.
3. 👥 **Очистка и объединение контактов**:
   - Нормализация номеров (`+7`, `8`, скобки, дефисы).
   - Умное объединение дубликатов контактов в 1 клик.
4. 🗑️ **Мусор и битые файлы**:
   - Сканирование 0-байтовых поврежденных файлов.
   - Поиск пустых папок от удаленных приложений.
   - Поиск забытых установочных `.apk` и временных файлов (`.tmp`, `.log`).
5. ⚡ **Мониторинг оперативной памяти (ОЗУ)**:
   - Аналитика в реальном времени через `ActivityManager.MemoryInfo`.
   - Быстрое ускорение и оптимизация системных буферов.
6. 🔐 **Генератор паролей (в стиле Kaspersky)**:
   - Криптографически надежный генератор (`SecureRandom`).
   - Индикатор надежности пароля и расчет времени на взлом брутфорсом.
   - Копирование в буфер обмена в один клик.
7. 👤 **Личный кабинет**:
   - Профиль пользователя, счетчик сэкономленной памяти за все время.
   - Управление подпиской и системные настройки.
8. 💳 **Монетизация (Google Play In-App Billing)**:
   - Тарифы: 1 Год (с триалом 3 дня), 1 Месяц, Навсегда (Lifetime).
   - Встроенный безопасный Sandbox Fallback для тестирования.

## 🏗️ Архитектура

Проект построен по принципам **Clean Architecture**:

```
app/src/main/java/com/novaclean/app/
├── domain/       # Бизнес-логика: модели, интерфейсы репозиториев, Use Cases
├── data/         # Данные: MediaStore, ContactsContract, FileSystem, GooglePlayBilling
├── presentation/ # UI: ViewModels (StateFlow), Jetpack Compose экраны, темы Material 3
└── di/           # Внедрение зависимостей (AppContainer)
```

---

## 🛠️ Стек технологий

- **Язык**: Kotlin 2.0+
- **UI**: Jetpack Compose + Material Design 3
- **Архитектура**: Clean Architecture + MVVM + StateFlow
- **Загрузка изображений**: Coil Compose
- **Биллинг**: Google Play Billing Library 7.x
- **Минимальный SDK**: Android 8.0 (API 26)
- **Целевой SDK**: Android 15 (API 35)
